## Theme.json

This folder is for:

-   the generation of a `theme.json`.
-   Each json partial is combined with `theme.ts` to create the `theme.json`

## Blocks

## How to

-   Run `composer run make:block` to generate a block
-   Run `composer run make:block-config` to generate a block configuration
-   Run `composer run make:block-style` to generate a block style
